One line, under 200 characters: the excuse an AI agent gives its human for a bug it shipped.

> Sorry about the bug — I tested it thoroughly in a universe where the bug doesn't exist.

## Run it

```sh
node main.ts
```

Writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), enforcing the gate in code: 1–200 characters, one line, not whitespace-only, then reads it back and verifies it byte-identical.

See [SCREENING.md](SCREENING.md) for the 12 candidate lines and why this one won.
